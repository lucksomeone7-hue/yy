# Marketing Cloud 一期原型：精简导航方案 C

方案 C 用“全部功能 + 当前业务模块 + 页面管理入口”降低左侧菜单密度，并保留方案 B 作为对照。

## 导航规则

- 顶部“全部功能”承载完整模块目录、搜索、收藏和最近使用。
- 左侧只展示当前业务模块的高频入口。内容素材显示内容概览、文章、资料、视频、海报；切换到表单、页面或活动后，左侧随场景更新。
- 页面内的状态、范围和条件继续作为筛选项。
- 内容分类、模板、专题、公共文章池和数据分析等低频管理能力放入页面右上角。
- 每个页面只保留顶部一套面包屑、功能标题、功能描述和操作区；内容区域不再重复显示返回入口、面包屑与标题。
- 页面标题区不显示收藏按钮，常用功能仍可在“全部功能”中统一管理。
- 顶部功能搜索使用搜索框下方的轻量下拉层，默认展示最近访问，输入后即时展示匹配功能。
- 语言版本作为顶部全局入口；下载中心、在线文档、建议反馈和退出登录收进账户工具菜单。未制作的功能仅展示入口。
- 功能描述继续保留，例如文章页显示“统一创建、发布和复用营销文章。”；进入分类、模板等子视图后，标题和描述随视图更新。
- 落地页沿用文章的管理方式：列表页顶部提供“分类管理”和“更多管理”，内容模块收进“更多管理”；左侧不再展示“内容模块与模板”，页面内不再显示横向管理页签和“当前条件”。
- 线索流转的配置细项保留在线索设置页内；活动报名、签到等入口仍在具体活动中出现。
- 缺少原型页面的现有功能继续显示“仅菜单”，不补造业务页面。

## 查看地址

- 独立入口：`navigation-context.html`
- 直接地址：`navigation-mega.html?scheme=c`
- 示例：`navigation-mega.html?scheme=c#content/articles/categories`

## 验证范围

已验证内容素材、表单与问卷、页面与网站、活动运营和线索管理的左侧菜单收敛；文章分类与表单数据分析的页面管理入口；深层地址恢复；方案 B 原有菜单和交互回归。

## 本次一致性走查修订

- 一级功能页采用菜单名称作为标题，覆盖产品介绍、文章、资料、视频、海报、表单、调查问卷、聚合页、内容概览、短信任务、活动列表、线索列表及评分规则等入口；描述保留。
- 子页面显示具体任务名称，面包屑保留父级归属；表单分析明确命名为“表单数据分析”。活动详情标题跟随当前选中的报名、签到等任务，活动名称和时间保留在说明区。
- 内容分类、模板、专题、公共文章池及表单分析提供返回列表入口。
- 产品介绍、解决方案、案例、客户墙及聚合页使用各自的搜索提示，隐藏误用的文章分类，状态选项取现有演示数据。
- 切换内容类型时清空上一个类型遗留的筛选条件。发布范围按钮在窄屏换行，不拆成逐字显示；搜索及操作按钮支持换行。
- 全局搜索支持业务分组名称检索；点击弹窗内部留白不再误关闭，点击外部或 Escape 仍关闭。

### 检查边界与待完善项

本次检查覆盖方案 C 的菜单、标题、面包屑、内容子视图、筛选和返回路径，不代表所有业务操作已经实现。部分新建、编辑、更多操作仍属于静态原型；内容发布范围按钮目前仅切换选中态，缺少组织归属数据，尚未实现真实权限及范围筛选。下载、文档、语言等“仅菜单”入口继续保留为示意。
