# 企业营销与联系人画像评审 · v2.1.0

日期：2026-10-20。面向市场人员开展营销，内部系统同步用于辅助销售了解营销动态。

## 评审入口

- 联系人画像：https://lucksomeone7-hue.github.io/yy/mk/navigation-mega.html?scheme=d#profileTags
- 企业营销洞察：https://lucksomeone7-hue.github.io/yy/mk/navigation-mega.html?scheme=d#account
- 企业列表：https://lucksomeone7-hue.github.io/yy/mk/navigation-mega.html?scheme=d#companies

## 评审重点

联系人画像回答：这个人已知什么、关注什么、能否触达、下一步如何培育。
企业画像回答：覆盖哪些人员和角色、多人关注什么、营销效果如何、哪些信号需要同步。
资料缺失、未发生行为与已确认低意向分别表达，资料完整度不计入意向分。

## 走查步骤

1. 联系人页切换六种数据场景：资料行为完整、新联系人、仅行为、有客户表达、资料与行为不足、历史沉默。
2. 核对各场景的已知信息、判断边界和建议动作；无触达渠道时只生成补充资料或站内建议待办。
3. 保存草稿或待办，检查页面回显；关闭窗口、切换场景后查看当前会话状态。
4. 从企业列表选择不同企业，核对名称、分数及合作背景。
5. 企业页切换四种数据场景；覆盖不足时确认不将单人兴趣作为企业确定需求。
6. 完整企业场景切换7/30/90天，检查互动指标和固定近7天分差的口径说明。
7. 查看客户表达和行为依据，确认推测兴趣与客户实际表达分开呈现。
