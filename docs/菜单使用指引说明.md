# 菜单使用指引 · v2.2.1

本次在方案 D 原界面上增加轻量提示，帮助用户发现现有入口；保持现有菜单层级、业务页面和导航状态。

## 交互

- 左上角保留原菜单图标，并增加“全部功能”文字。
- 顶部“菜单指引”可随时重看，窄屏显示带可访问名称的问号入口。
- 首次正常进入工作台，700ms 内未开始其他操作时，提示“活动、内容、线索等功能，都可以从这里进入”。
- 点击“展开菜单”复用原全部功能弹窗，第二步说明业务分类与星标收藏；不自动切换分类、收藏或进入页面。
- 指引以非模态气泡显示，第二步挂载在原菜单 dialog 内，保留菜单查找、分类、收藏和业务跳转。
- 关闭、知道了、Esc 或完成后记录状态；跳转业务页面也会撤去指引。
- 深链、明确的菜单打开参数及已有弹窗不自动启动，搜索快捷键优先执行原有行为。

## 范围

- 原型入口：`/mk/` → `navigation-admin.html` → `navigation-mega.html?scheme=d#dashboard`。
- 新增独立文件 `navigation-guide.js` 和 `navigation-guide.css`，不向 B/C 方案启用指引。
- 记录键为 `mk-menu-guide-v1`，优先使用 localStorage，会话存储作为降级；两者均禁用时只保持当前页面状态。
- 不修改现有 `mk-mega-favorites`、`mk-mega-recent` 或 `mk-mega-collapsed` 的保存逻辑。
