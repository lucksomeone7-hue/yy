# MK 列表筛选与交互统一规范（对齐营销云 V1.0）

- **版本**：v1.1（2026-09-11）
- **性质**：本规范是营销云《列表筛选与交互统一规范 V1.0》的 **MK 落地版**。其中通用交互规则为系统规范，四模块实测内容为专项整改依据，不自动升级为全系统强制规则。
- **前身**：合并自《MK列表页通用规范 v1.2》《MK列表页字段规格 v1.3》，并按营销云统一规范对齐口径。
- **适用范围**：MK 后台所有「列表页」——含表格展示、关键字搜索、高级筛选、行操作、分页、空态。表单、弹窗、数据治理和接口改造仅作为专项检查项，不属于列表 UI 统一规范。
- **首批覆盖**：内容中心（文章 / 资料 / 视频）、活动中心（活动）。
- **适用对象**：产品（评审）、前端（开发）、测试（验收）。
- **依据**：营销云统一规范 V1.0 + 四模块运行时实测（表头宽度、筛选项 value/label、Vue 实例数据）。

## 1. 术语与统一口径

### 1.1 发布范围（替代原「归属 / 资料归属」）

涉及内容归属的页面**统一使用「发布范围」**，选项与含义固定如下：

| 选项 | 含义 | MK 取值约定（后端） |
|---|---|---|
| 全部 | 当前用户有权限查看的全部记录 | `""` 或 `all` |
| 本人发布 | 当前登录用户发布的记录 | `my` |
| 所在组织发布 | 当前登录用户所在组织发布的记录，**包含本人发布** | `org` |
| 其他组织发布 | 不属于当前登录用户所在组织、但当前用户有权限查看的记录 | `other` |

- ⚠️ **语义变更**：原 MK「本组织」是否包含本人发布需与后端确认；新规要求 **所在组织发布 必须包含本人发布**（与营销云一致）。
- 不得使用「数据范围」「机构」「所在组织」「其他」「我创建的」「他人创建的」等作为同一维度的页面文案。
- 发布范围只在用户已有数据权限内切换；服务端始终负责最终权限判断（A7）。

### 1.2 搜索 / 查询 / 重置 / 高级筛选 / 清空筛选

- 内容 / 记录型列表按钮文案使用 **「搜索」**；MK 四模块均按「搜索」处理（A3）。
- **「重置」**：清除当前页面全部筛选条件并恢复默认状态。不得使用「清空」「恢复」替代。
- **「清空筛选」**：**仅用于空态恢复入口**（见 §4），避免与普通重置按钮混淆。
- **「高级筛选」**：收起时为「高级筛选⌄」，展开时为「收起筛选⌃」。

### 1.3 MK 全局术语表

| 概念 | 统一用词 | 禁用 |
|---|---|---|
| 内容归属维度 | 发布范围 | 归属 / 资料归属 / 数据范围 / 机构 |
| 发布范围选项 | 全部 / 本人发布 / 所在组织发布 / 其他组织发布 | 我创建的 / 本组织 / 他人创建的 / 所有 |
| 搜索入口 placeholder | 请输入关键字 | 请输入您搜索的内容 |
| 重置按钮 | 重置 | 清空 / 恢复 |
| 空态恢复入口 | 清空筛选 | 重置 |
| 视频维度 | 视频类型 | 视频来源 |
| 封面缩略图 | 封面 | 视频 |
| 分类为空 | 未分类 | — / 空 |
| 统计无数据 | —（+hover 说明） | 空白 |

## 2. 筛选区布局（两行式）

### 2.1 通用布局

有发布范围的列表页按两行组织，阅读与操作顺序固定：

```
第 1 行：发布范围  [ 全部 ] [ 本人发布 ] [ 所在组织发布 ] [ 其他组织发布 ]
第 2 行：关键词 / 常用下拉条件  →  搜索  →  高级筛选（如有）  →  重置
第 3 行：已选条件回显（结果数 + 条件标签）   ← 见 §3.3
第 4 行：表格
```

- 「发布范围」置于筛选卡片第一行左侧，采用同一组横向标签按钮。
- 第二行从左到右：先输入和下拉条件，再放执行（搜索）与恢复（重置）操作。
- 搜索按钮紧跟最后一个常用条件；高级筛选与重置位于其右侧。
- 高级筛选默认收起，优先在当前筛选卡片内展开；若条件数量较多，可采用抽屉等承载方式，但必须保留统一提交、已选条件回显和清晰的关闭路径。展开后应控制高度，避免长期挤占首屏表格。
- 页面主操作（如「新建文章」「新建活动」）= 红色主按钮，置于标题区右上，不与筛选按钮混排。

### 2.2 各模块落地映射

| 页面 | 第一行 | 第二行常用条件 | 高级条件 |
|---|---|---|---|
| 文章列表 | 发布范围 | 关键词、分类、状态、类型、上架官网 → 搜索 → 高级筛选 → 重置 | 行业、领域、发布者、创建时间 |
| 资料列表 | 发布范围 | 关键词、资料分类、资料类型、可见范围、状态 → 搜索 → 高级筛选 → 重置 | 上传人、上传时间 |
| 视频列表 | 发布范围 | 关键词、视频类型、分类、时间区间 → 搜索 → 高级筛选 → 重置 | 上传人、可见范围 |
| 活动列表 | 发布范围 | 关键词、活动状态、发布人、活动形式 → 搜索 → 高级筛选 → 重置 | 创建时间、可见范围、**承办方（仅我承办）** |

> 常用与高级划分原则（营销云 §4.3）：常用 = 关键词、类型、状态、时间范围 + 一个高频业务维度；其余低频维度（行业、上传人、创建时间、可见范围等）放入高级筛选。仅 2–3 个常用条件时不强行增加高级入口。

### 2.3 常用 / 高级条件划分（MK 定制）

- **文章**：行业 / 领域属内容标签体系（推荐分发用），归高级；发布者、创建时间归高级。
- **资料 / 视频 / 活动**：上传人 / 创建时间 / 可见范围归高级。
- **活动**：原「场景」筛选项已确认移除（业务不做场景筛选），同步删除参数 `scene` / `sceneList`。

## 3. 控件与状态

### 3.1 按钮规范

| 控件 | 视觉与位置 | 行为 |
|---|---|---|
| 搜索 | 红色主按钮，位于常用条件之后 | 应用当前全部筛选条件；关键词框按 Enter 与点击效果相同。 |
| 重置 | 描边次按钮，位于筛选行最右 | 恢复页面默认筛选、收起高级筛选、回到第一页并重新查询；**清空列表勾选**。 |
| 高级筛选 | 描边次按钮，位于搜索之后、重置之前 | 收起「高级筛选⌄」/ 展开「收起筛选⌃」；展开为内联区域。 |
| 页面主操作 | 红色主按钮，标题区右上（如「新建文章」） | 打开创建流程，不与筛选按钮混排。 |

> ⚠️ **冲突处理（重要）**：文章模块现有高级筛选内「查询 / 清空」双按钮模式，与营销云「单一搜索 + 重置 + 高级筛选折叠」冲突 → **统一改为规范模式**（搜索 + 重置 + 高级筛选 toggle），「清空」仅保留为空态入口（§4）。

### 3.2 条件生效与保留

- 页面有搜索按钮时，输入、下拉和高级条件在执行搜索后生效；切换页面、收起高级筛选时保留已输入 / 已应用的值。
- 发布范围可作为快捷范围切换立即生效；立即生效时必须同时保留其余已应用条件，不能静默丢失。
- 重新查询、切换发布范围、重置条件后，分页回到第一页。
- 筛选改变结果集时，默认清除当前列表的勾选项，防止对不可见记录执行批量操作。

### 3.3 已选条件回显

执行筛选后，在筛选区下方或结果标题旁展示：

- **结果数量**，如「符合条件 12 条」；
- **已生效的非默认条件标签**，如「发布范围：本人发布」「状态：已上架」；
- 高级筛选收起后，已生效的高级条件仍必须可见（如「行业：财务」「创建时间：2026-08」）。

条件标签应支持**单项移除**；移除后立即按剩余条件刷新结果。默认值（如「全部」）不必重复显示为条件标签。

## 4. 空态与异常四态

筛选无结果、完全无数据、加载失败、无权限**必须分别表达**，不能都显示为「暂无数据」。

| 状态 | 文案示例 | 下一步入口 |
|---|---|---|
| 筛选无结果 | 「没有符合条件的文章」+「请调整发布范围或关键词后重试」 | **清空筛选**（恢复默认并重新查询） |
| 完全无数据 | 「还没有任何文章」 | **新建**（创建入口） |
| 加载失败 | 「数据加载失败」 | **重试**（重新请求） |
| 无查看权限 | 「您没有查看该范围的权限」 | 说明无法查看的范围 / 申请权限 |

- 错误状态提供重试；无权限状态说明无法查看的范围；加载状态保留表格骨架，避免页面跳动。
- 「清空筛选」与「重置」语义不同：前者仅在筛选无结果空态出现，后者为筛选区常驻按钮。

## 5. 表格与列表布局原则

1. 标题、核心业务信息、状态和操作按阅读优先级排列；名称/标题通常在最左，操作在最右。
2. 宽表格的名称列和操作列可固定，保证横向滚动时仍能识别记录并完成操作。
3. 状态使用统一颜色和文字，不只依赖颜色传递含义。
4. 筛选卡片与结果表格之间保留明确间距；筛选区不因高级条件常驻而压缩首屏结果。
5. 在 1280 / 1440 / 1920px 宽度下检查：筛选控件不换行遮挡、操作列可见、长文本有截断或换行策略。

## 6. MK 专项质量条款（来自实测走查）

以下条款为 MK 四模块实测发现的专项问题，等级沿用 MUST/SHOULD/MAY。

其中 R/C/V/F/N/O/B/P/T 属于列表页面专项规则；M/X/G 属于表单、工程和数据质量检查项，用于关联整改和发布验收，不作为营销云列表 UI 统一规范的继承条款。

### 6.1 布局与响应式（R）

| 编号 | 条款 | 等级 | 现状（实测） |
|---|---|---|---|
| R1 | 页面**不得硬编码** `body{min-width:1920px}`；后台应覆盖 **1280px** 及以上常用桌面宽度 | MUST | 🔴 框架级硬编码 → 1440/1366 下整页横向滚动 |
| R2 | 列表容器**不得用 `overflow-x:hidden` 吞掉内容**；溢出时必须可横向滚动或列宽收敛 | MUST | 🔴 操作列被静默裁掉且无法滚动到 |
| R3 | 「操作」列**必须** `fixed="right"` | MUST | 视频已用；资料/文章未用 |
| R4 | **1280px** 下操作列、状态列和核心业务列必须可访问；必要时允许表格内部横向滚动 | MUST | 文章 1366 下编辑/上架/更多全在屏外 |
| R5 | 验收宽度至少覆盖 1280 / 1440 / 1920；MK 可增加 1366 / 1680 两档 | SHOULD | 仅按 1920 设计 |

### 6.2 表格列（C）

| 编号 | 条款 | 等级 |
|---|---|---|
| C1 | 列宽策略：内容列弹性（`min-width`），非内容列固定（`width`）；非内容列不得参与弹性分配 | MUST |
| C2 | 优先通过弹性列和列宽收敛适配容器；无法合理压缩时允许表格内部横向滚动，禁止整页滚动或静默裁切 | MUST |
| C3 | 每列必须有表头；缩略图列名明确（如「封面」） | MUST |
| C4 | 列名必须与渲染内容一致 | MUST |
| C5 | 状态类列必须视觉区分（`el-tag`），不得一律灰字 | MUST |
| C6 | 长文本必须有明确策略，可采用单行省略 + tooltip，或在业务需要时限制行数换行 | SHOULD |
| C7 | 主指标统计列必须展示且支持列头排序（文章/活动/资料保留；**视频经产品确认不放分享、收藏、时长**） | SHOULD |
| C8 | 高风险属性列必须展示（如「可见范围」公开/私有） | SHOULD |
| C9 | 语义相近列需合并或明确区分 | MAY |

### 6.3 默认视角（V）

| 编号 | 条款 | 等级 |
|---|---|---|
| V1 | 列表**默认必须为「全部」**（发布范围默认「全部」），不得默认携带筛选条件 | MUST |
| V2 | 若因业务必须带默认条件，收起态必须在按钮上显示「已筛选(N)」角标 | MUST |
| V3 | 同类模块默认视角必须一致 | MUST |
| V4 | SPA 路由切换后若保留上次筛选，必须有可见提示 | SHOULD |

### 6.4 筛选器（F）

| 编号 | 条款 | 等级 | 现状 |
|---|---|---|---|
| F1 | 筛选是筛选、排序是排序，严禁把排序控件放进筛选区 | MUST | 🔴 活动「活动时间」实为排序器 |
| F2 | 高级筛选区折叠展开，单一「搜索」提交；**不得**在高级区内另设「查询 / 清空」按钮（冲突项，见 §3.1） | MUST | 🔴 文章高级区有「查询 / 清空」 |
| F3 | 筛选 label 与 placeholder 语义必须一致 | MUST | 🔴 资料类型 placeholder 写「请选择分类」 |
| F4 | 筛选项 value 必须与后端数据取值一致，上线前逐项回归 | MUST | 🔴 资料状态 value=`"2"` 数据实为 `0/1` |
| F5 | 枚举必须来自有效业务字典或接口约定；零命中选项需确认是否仍有效，不能只因当前无数据直接删除 | MUST | 🔴 资料类型 ppt/excel/视频 当前全库 0 命中，需联合产品和接口确认 |
| F6 | 同一维度术语必须唯一 | MUST | 🔴 视频「类型 / 来源」混用 |
| F7 | 能筛的维度必须有对应展示列 | SHOULD | 资料「可见范围」可筛不可见 |
| F8 | 查询筛选器内禁止新建业务对象（如「回车添加自定义分类」） | MUST | 🔴 文章/资料下拉可新建分类 |
| F9 | 枚举 value 禁止魔法数字，改用可读枚举 | SHOULD | 🔴 视频来源 value `1/2/9` |
| F10 | 枚举筛选应提供「未分类 / 未设置」选项 | SHOULD | — |
| F11 | 时间筛选必须是范围选择器，全天活动显示「全天」 | MUST | 活动无时间范围筛选 |
| F12 | 页顶说明编号顺序必须与下拉选项顺序一致 | SHOULD | 🔴 视频说明与下拉顺序错位 |
| **F13** | **发布范围**统一维度，4 固定选项；参数建议 `rangeType`；默认「全部」 | MUST | 原「归属」改名对齐（A1） |
| **F14** | 按钮规范：搜索=红主 / 重置=描边 / 高级筛选=折叠 toggle / 主操作在标题区右上 | MUST | 见 §3.1 |
| **F15** | 同一页面不出现两个同义提交按钮；内容型列表统一用「搜索」 | MUST | 文章「查询」需统一为「搜索」 |
| **F16** | 已选条件回显：结果数 + 非默认条件标签 + 高级条件收起可见 + 单项可移除 | MUST | 见 §3.3 |

### 6.5 空值（N）

| 编号 | 类型 | 展示 | 等级 |
|---|---|---|---|

## 12. 跨模块矛盾清单（Bug 级）

### 12.1 🔴 状态 value 冲突
文章 `1=上架/0=下架`；资料 `"1"=上架/"2"=下架`（数据实为 `0/1`）。→ UI 状态语义保持一致，资料筛选值须与实际数据修正为一致；是否统一后端枚举需结合接口兼容性另行评估。

### 12.2 🔴 发布范围默认值冲突
资料默认 `my`（隐藏他人 3 条）；活动默认 `all`。→ 默认统一「全部」。

### 12.3 🟠 参数名拼写
`rangType`（活动）vs `rangeType`（资料）。→ 统一 `rangeType`。

### 12.4 🟠 活动筛选与展示不同源
筛选「活动状态」6 种 vs 列表「审核」2 种。→ 列表补「活动状态」列，两列并存且各自明确。

### 12.5 🟠 统计字段存在但值空
文章/活动 `countForward`/`countFavorite` 字段在、值为空；非字段缺失。→ 文章/活动/资料列保留按空值规范渲染（0→`0`、null→`—`），排查后端回填；视频经确认不放列。

### 12.6 🟠 上架官网 value 语义反转
`0=开启/1=关闭` 与常见认知相反。→ UI 统一显示「是/否」，前端先通过映射层适配；是否修改接口值及存量数据另行评估。

## 13. 验收清单（上线前逐项打勾）

**A. 术语与布局**
- [ ] 同一业务范围均为「发布范围」，4 选项名称与含义一致（F13）
- [ ] 筛选区两行式：发布范围在第一行，关键词→条件→搜索→高级筛选→重置（§2.1）
- [ ] 搜索/重置/高级筛选名称、位置、视觉与规范一致（F14）；高级筛选折叠态文案正确
- [ ] 同一页面无两个同义提交按钮（F15）

**B. 生效与回显**
- [ ] Enter 与搜索一致；条件生效时机明确；切换发布范围不丢失其他已应用条件
- [ ] 查询后能看到结果数和所有非默认已选条件，高级条件收起后仍可识别（F16）
- [ ] 重置恢复默认、清空勾选、回第一页并重新加载

**C. 默认与筛选**
- [ ] 发布范围默认「全部」（V1）
- [ ] 每个筛选项来自有效业务字典或接口约定；零命中项已确认是否仍有效（F5）；value 与数据一致（F4）；label 与 placeholder 同义（F3）
- [ ] 无"筛选区放排序"（F1）、无"筛选器新建分类"（F8）；时间筛选为范围选择器（F11）

**D. 表格**
- [ ] 1280/1440/1920 三档操作列均可访问，并补充验证 1366/1680（R4/R5）；无横向滚动吞列（R2）；操作列 `fixed="right"`（R3/O1）
- [ ] 列宽优先适配容器，超出时使用表格内部横向滚动且关键列可访问（C2）；每列有表头且名实一致（C3/C4）；状态列用 tag（C5）
- [ ] 已接入且有业务价值的统计列已展示并按需支持排序（C7）；高风险属性列（可见范围）已展示（C8）

**E. 数据展示**
- [ ] 0→`0`、null→`—`、未归类→「未分类」（N1–N4）；统计列按接入状态和业务价值决定展示（N6）；空值排序在最后（N5）

**F. 操作与批量**
- [ ] 有明确批量业务需求的页面提供复选框和对应批量操作（B1/B2）；通用操作外露、专属入「更多」分组（O2）；危险操作二次确认（O6）

**G. 分页与空态**
- [ ] 无 1000 条/页（P1）；筛选后重置到第 1 页（P3）
- [ ] 空态四态区分：筛选无结果（清空筛选）/ 无数据（新建）/ 加载失败（重试）/ 无权限（说明）（§4）

**H. 文案与反馈**
- [ ] placeholder 全站统一（T2）；toast 精确到动作（T3）；耗时操作有反馈（X1）；全流程零 JS 报错（X2）

**I. 数据**
- [ ] 生产库无测试数据（G1）；必填字段非空且已 trim（G2）

## 14. 维护规则

新增管理页或调整现有筛选时，先按本规范确定筛选维度、默认值、结果回显和空态，再进入视觉设计和开发。模块独有条件可按频率进入常用或高级筛选；只有在术语、布局、生效方式、状态反馈等统一规则上确需偏离时，才应在页面 PRD 中写明偏离原因、目标用户和验收方式，并同步更新本规范版本。
