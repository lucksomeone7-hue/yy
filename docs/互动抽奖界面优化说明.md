# 互动抽奖界面优化

本次针对大屏列表、奖项设置和中奖名单的操作层级与空间利用进行优化，沿用原仓库的 HTML、CSS、原生 JavaScript 及用友品牌色。

## 入口与布局

- 管理员导航 → 活动列表 → 管理活动 → 互动抽奖。
- 签到与互动页面也可通过“管理互动抽奖”进入。
- 直接访问 `prototype/navigation-admin.html#activityDetail/lottery`，刷新可恢复该入口。
- 大屏管理与具体大屏详情分层；详情包含“奖项设置 / 抽奖池名单 / 中奖记录”。
- “打开大屏”为主要操作；大屏内可选择幸运转盘、单人滚动、头像矩阵、砸金蛋、幸运老虎机、名单滚动、3D 球形，共七种形式。
- 展示舞台与控制台分区，可收起控制台或进入全屏；支持红金盛典、深蓝星光两套主题与减少动态效果。
- 奖项卡片统一展示名额、已抽和剩余数量，新增入口缩为正常按钮及紧凑虚线卡。
- 空名单和空记录展示下一步引导，零结果不展示无意义分页。

## 抽奖动效与研发入口

- 直接打开 `prototype/lottery-preview.html`，自动进入抽奖舞台；普通管理入口仍保持原有路径。
- 新浏览器内置 64 位虚构参与人；旧记录保留，可通过“补齐内置示例人员”合并缺失示例，已导入名单和中奖记录继续保留。
- 七种形式共用奖项、名单与记录：开始仅运行视觉循环，停止时一次性生成并保存结果，再播放减速与揭晓。
- 滚动时关闭取消本轮，停止后关闭保留结果；中奖人员从后续所有奖项中排除，名额用尽后禁止继续抽取。
- 展示引擎与结果控制器独立。研发可查看 `prototype/lottery-motion-guide.html` 或 [完整动效与研发交接说明](./互动抽奖动效与研发交接.md)，包含各形式时序、缓动、四阶段状态、接口契约与验收清单。

## 原型边界

这是现有静态原型中的可交互演示。示例数据明确标识；修改保存在当前浏览器本地，未连接正式人员数据或抽奖服务，不跨设备同步。正式活动需要接入服务端名单、权限与抽奖结果存储。

新增样式使用 `lottery-` 前缀，仅在抽奖面板激活时隐藏活动概览。其他活动功能与原导航继续使用现有实现。

本次变更位于功能分支，未发布新正式版本；版本号、稳定版地址和历史归档遵循 `VERSIONING.md`，在正式发布时统一更新。
