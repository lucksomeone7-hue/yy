# Marketing Cloud 一期原型：导航布局修订版

本次调整仅涉及导航、菜单归属和必要的页内导航，不新增业务页面或模拟现有系统尚未进入原型的功能。

## 依据与范围

- 原型基线：v1.1.0，`prototype/`。
- 现状截图：顶部首页、用户中心、落地页、活动中心、内容中心、营销中心、线索中心、网站中心、系统设置。
- 补充依据：历史任务“系统走查并修订页面原型-线索中心”保存的全模块只读走查结论。
- 本次用户提供的 ChatGPT 分享链接未能成功读取，以上述已保存走查结论恢复范围。报告不是逐条系统菜单导出，因此不声称复刻了旧系统每个配置子项。
- 已确认现有能力与报告中的未来建议分别处理：营销项目、预算、ROI、归因规则、异常任务中心等建议能力不作为现有菜单补建。

## 布局

顶部：品牌、原型版本提示、功能菜单搜索、当前组织。
左侧第一列：工作台、客户与人群、内容与页面、活动管理、营销触达、线索管理，系统设置固定底部。
左侧第二列：仅显示当前模块的功能，分类标题不可点击、不折叠；可整体收起。
活动管理只有一个列表入口，直接进入列表并收起第二列，报名、签到、直播等继续位于活动详情内。
内容区：当前位置、页面标题、收藏、必要的页内标签和原有业务页面。

## 仅菜单规则

网站管理、邮件营销、微信营销、营销自动化、全员营销、渠道管理、组织管理，共 7 项。

- 显示“仅菜单”，说明原型覆盖状态，不使用“无权限”或“建设中”假定真实系统状态。
- 点击仅显示短提示，保持当前业务页面及当前位置，不创建空白页、数据、表格或业务操作。
- 功能搜索可发现这些入口，但不会跳转到无关页面。
- 不添加业务详情子菜单，避免把建议能力误认成系统已有能力。

## 导航行为

- 当前页与所属业务模块同步高亮，详情页归属父级列表。
- 全部功能支持名称搜索和旧菜单别名搜索；仅搜索功能，不假装搜索真实客户数据。
- 收藏与最近访问只存于当前浏览器，不代表账号级持久化。
- 一级模块记忆本次会话最近访问的功能。
- 内容、短信、评分配置支持地址定位和浏览器返回。
- 功能栏可收起；1280、1050、700px 设置导航响应式断点，实际业务页面沿用原有响应式规则。
