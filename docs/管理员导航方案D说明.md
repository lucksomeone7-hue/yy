# 管理员导航方案 D

## 设计判断

MK 同时包含运营工作、内容资产、触达任务、线索流转与组织配置。管理员需要快速跨模块，同时也需要在处理具体任务时减少无关菜单干扰。

方案 A 的双栏提供稳定定位，但长期占用页面宽度；方案 B 完整展示功能，分组展开后容易变长；方案 C 减少了当前菜单，但层级关系仍不够统一。方案 D 将“全部功能”作为唯一的跨模块入口，进入功能后左侧只显示当前模块，并用单开手风琴展示列表、分类、模板等固定管理入口。

这是基于现有原型和已确认需求的设计判断，尚未经过真实管理员的可用性测试。

## 菜单分配

| 全部功能中的模块 | 进入模块后显示的入口或分组 |
| --- | --- |
| 工作台 | 经营看板、行动待办；已收藏功能显示在工作台菜单 |
| 客户与人群 | 联系人、企业客户、人群分组、意向分层；联系人画像从列表“查看画像”进入；意向评分配置：评分规则、行为权重、规则版本 |
| 内容与页面 | 内容概览；文章：列表、分类、模板、专题、公共文章池；资料/视频/海报：列表、分类；表单：列表、数据分析；调查问卷；落地页：列表、分类、内容模块；聚合页、网站管理；产品介绍、解决方案、客户案例、客户墙 |
| 活动管理 | 活动运营：活动专题、活动列表、活动分类；统计分析：场次、人数、活动、机构、直播统计及定制报表；其他管理：回收站 |
| 营销触达 | 短信营销：短信任务、短信模板；邮件营销：邮件列表、邮件模板；微信营销：公众号管理；营销自动化；全员营销：活动列表、分享排行 |
| 线索管理 | 线索列表、流转配置 |
| 系统设置 | 组织与权限：组织管理、账号管理、角色管理；渠道配置：渠道管理、渠道分类；基础设置：字段配置、绑定微信 |

意向评分规则与线索流转属于业务配置，仍保留在对应业务模块；字段、公众号绑定等组织级配置归系统设置。

## 交互规则

1. 顶部“全部功能”负责跨模块和一级功能切换。弹窗只展示文章、资料、落地页等一级功能；分类、模板等管理项不在弹窗中重复铺开。
2. 选择一级功能后关闭弹窗，左侧只显示当前模块，并展开当前功能的二级菜单。例如进入文章后显示文章列表、文章分类、文章模板、文章专题和公共文章池。
3. 模块内分组全部可见，最多展开一个。点击其他分组只切换展开状态，不自动跳页；选中功能后才跳转。
4. 列表、分类、模板、专题等独立管理功能固定在左侧菜单，页面顶部不再保留重复的分类、更多管理和返回列表入口。状态、发布范围继续作为筛选，不升级成导航层级。
5. 报名、签到、直播等只在具体活动详情出现；左侧保留活动名称和返回活动列表入口。
6. 进入功能、打开深链和浏览器回退时，同步分组展开、菜单高亮、面包屑与标题。
7. 次级菜单可收起；需要切换模块时从顶部“全部功能”进入。
8. 全部功能弹窗支持收藏、最近访问和功能搜索；顶部搜索仍在搜索框下方展开，支持搜索分类、模板等深层入口及旧名称。
9. 工作台左侧最多展示 7 个收藏入口；超出后显示“更多收藏”，点击进入全局菜单的完整收藏列表。未收藏星标仅在菜单项悬停或聚焦时显示。
10. 语言和账户工具位于右上角。下载、在线文档、反馈等入口保持统一的菜单样式。
11. 没有原型页面的功能不显示额外状态标识；入口保持不可跳转，点击时说明暂无页面，不改变当前页面或伪造业务内容。

## 验收建议

请管理员分别尝试：找账号管理、找绑定微信、从文章切到落地页、从活动列表进入签到、从线索列表进入流转配置、从全局搜索打开短信模板。观察是否能直接定位、是否误把筛选当导航、返回后是否清楚当前位置。
