# 菜单动效 · v2.2.2

在现有管理员原型上补充鼠标移入与窗口开合反馈，继续通过点击“全部功能”打开菜单。

## 动效规则

| 对象 | 行为 |
| --- | --- |
| 全部功能入口 | 约 140ms 的淡红高亮、文字变色和线条反馈；展开时汉堡图标变为关闭图标。 |
| 分类及功能项 | 约 140ms 的背景、文字过渡；精细指针下轻移 2px，键盘聚焦保持可见反馈。 |
| 全部功能窗口及遮罩 | 180ms 淡入、140ms 淡出；窗口内部内容从上方轻移进入。 |
| 关闭行为 | 关闭按钮、Esc、点击遮罩和进入业务页统一执行退出动效，实际关闭后恢复焦点。 |
| 减少动态效果 | 跳过位移与过渡，立即执行关闭；保留明确的选中及展开状态。 |

窗口本体不使用 transform，保持现有指引气泡的视口坐标稳定。分类、收藏和搜索重绘不重新触发整窗入场。关闭动画缺少完成事件时由定时器兜底，重开会取消旧退出任务。

## 实现范围

- 新增 `prototype/navigation-menu-motion.css` 与 `prototype/navigation-menu-motion.js`。
- `navigation-mega.js` 将原全部功能窗口开合接入动效控制器；B/C 仍使用现有行为。
- `navigation-guide.js` 的 Esc 关闭接入同一流程，焦点等待窗口实际关闭再返回。
- 不新增自动悬停打开，不改变菜单结构和业务数据。

- 浏览器确认指引退出动画期间打开功能搜索，上层搜索框保持焦点；控制台未出现错误。
