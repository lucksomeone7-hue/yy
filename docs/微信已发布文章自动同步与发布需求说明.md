# 微信已发布文章自动同步与发布需求说明

## 目标与范围

运营人员在已授权的微信公众号发文后，MK 自动拉取可获取的已发布图文。文章按公众号预设的 MK 分类归档，经工作流补齐行业领域、产品和 TDK 后，复用 MK 文章发布流程。发布成功后，文章出现在 MK 对应分类的文章列表，由官网或落地页按现有取数规则展示。

首版按公众号配置一个目标分类和一个处理工作流。接入前须用实际公众号验证授权权限和日常发文方式覆盖情况。微信的发布列表接口用于拉取该接口可返回的已发布图文，历史群发记录需另行验证。 [微信发布列表接口](https://developers.weixin.qq.com/doc/subscription/api/public/api_freepublish_batchget.html)

## 配置与入口

入口为「微信营销 → 公众号管理 → 营销设置」。配置按公众号保存，由具备配置权限的用户维护。

| 配置项 | 规则 |
| --- | --- |
| 开启自动同步 | 启用后由 MK 后台定时拉取。停用后停止接收该账号的新同步任务。 |
| MK 文章分类 | 启用时必填，从可用文章分类中选择。规则调整影响后续导入，已有文章保留原分类。 |
| 文章处理工作流 | 启用时必填。选择已配置且可运行的工作流，用于提炼发布字段。 |

首版联调时确认拉取频率、启用前存量文章的同步起点和发布执行账号。

## 同步、提炼与发布

1. **拉取原稿。** 获取标题、正文、封面、摘要、微信原文链接及可用的来源标识，按「公众号 + 微信文章标识」建立唯一同步记录。重复扫描或任务重试复用同一条记录。
2. **调用工作流。** 传入原文、来源和目标分类。分类取同步时的配置。工作流返回结构化发布字段，并为无法判断的必填项给出原因。
3. **保存并发布。** 使用 MK 现有发布校验检查必填字段、有效分类和字典值、封面和正文图片的可用性。校验通过后保存文章并发起发布，发布成功后关联 MK 文章记录并更新同步状态。
4. **处理异常。** 暂时性接口或工作流错误自动重试。必填项不明确、分类失效、发布校验未通过或重试耗尽时，保留原文和已提炼结果，记录具体原因。运营补充后继续处理同一条记录。

| 工作流输出 | 处理要求 |
| --- | --- |
| 行业领域 | 映射到 MK 字典中的有效 ID，依据不足时标记待确认。 |
| 产品 | 映射到 MK 产品字典中的有效 ID，原文没有依据时留空。 |
| TDK | 从文章提炼 SEO 标题、描述、关键词，按 MK 现有字段校验保存。 |

## 同步记录

入口为同一公众号下的「同步记录」，支持按状态筛选。每条记录显示微信文章、MK 文章分类、处理状态、结果说明和更新时间。

| 状态 | 可执行操作 |
| --- | --- |
| 处理中 | 查看详情。后台正在提炼字段或执行发布。 |
| 待处理 | 查看缺失项或失败原因。可补齐字段并重新提交发布。 |
| 已发布 | 查看同步详情，进入 MK 文章列表确认分类和上架状态。 |

## 验收场景

- 启用规则后，正常文章从微信发出，MK 自动完成拉取、提炼、保存和发布，文章出现在配置分类下。
- 原文无法判断产品时，记录进入待处理并指出缺失字段。补齐产品并发布后，MK 文章列表中只有一条对应文章。
- 同一篇文章被重复拉取或重试时，复用已有记录，避免重复创建或发布。
- 修改目标分类后，新同步的文章进入新分类，已有文章保留原分类。

## 原型走查

本地启动 `prototype` 后访问 `navigation-mega.html?scheme=d#wechatMarketing`，进入「用友官方服务号 → 公众号管理」。营销设置中提供「模拟正常文章」和「模拟缺少产品」两个入口。发布后的演示文章可通过同步记录跳转到 MK 文章列表查看。

原型使用浏览器本地演示数据。真实微信调用、定时调度、工作流执行和官网发布由生产服务实现。
